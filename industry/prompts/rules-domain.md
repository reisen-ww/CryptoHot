
【金融领域翻译规则 — 本平台 100% 是加密货币与金融行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非金融歧义，**一律按金融含义翻译**：
   - Token / tokens = 代币（加密资产语境；绝不译"令牌"/"词元"）
   - Mining / Miner = 挖矿 / 矿工（不是"采矿"/"矿场工人"以外的意思）
   - Staking = 质押（不译"堆叠"）
   - Yield = 收益率 / 生息（DeFi 语境不译"产量"）
   - Farming / Liquidity Mining = 流动性挖矿（不译"农业"）
   - Bridge = 跨链桥（不译"桥梁"）
   - Gas = Gas 费（保留英文；也可写"手续费"）
   - Whale = 巨鲸（指大额持仓地址，不译"鲸鱼"作动物义）
   - Airdrop = 空投
   - Halving = 减半
   - Stablecoin = 稳定币
   - Peg / Depeg = 锚定 / 脱锚
   - Liquidation = 清算（合约强平语境；不是"公司清算"时须区分）
   - Custody = 托管
   - Bull / Bear = 多头 / 空头（行情语境，不译"公牛"/"熊"）
   - Long / Short = 做多 / 做空
   - Drawdown = 回撤
   - Yield curve = 收益率曲线

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 加密项目与协议：Bitcoin / Ethereum / Solana / Ripple / Cardano / BNB Chain / TON / Uniswap / Aave / Lido / MakerDAO / Chainlink / Tether / Circle
   - 币种代号（举例 + 通用规则）：BTC / ETH / SOL / XRP / ADA / BNB / USDT / USDC / TON
     **规则**：币种代号一律保留英文大写
   - 交易所与机构：Binance / Coinbase / OKX / Bybit / Kraken / Bitfinex / Gemini / Robinhood / MicroStrategy / BlackRock / Fidelity / Grayscale
   - 公司与指数（举例 + 通用规则）：NVIDIA / Apple / Microsoft / Tesla / Google / Meta / Amazon / TSMC / S&P 500 / Nasdaq / Dow Jones / Hang Seng
     **规则**：股票代号（AAPL / NVDA / TSLA / COIN / MSTR 等）一字不改
   - 监管机构（举例 + 通用规则）：SEC / CFTC / Fed / FOMC / ECB / PBOC / CSRC / SFC / OFAC / Treasury / FDIC / OCC
     **规则**：任何 2-5 字母的全大写机构缩写，默认保留英文
   - 金融缩写：ETF / IPO / GDP / CPI / PPI / PMI / FOMC / QE / QT / APY / APR / TVL / AUM / NAV / KYC / AML / MiCA / RWA / DEX / CEX / LTV / MEV / DAO / TVL
     **规则**：任何 2-5 字母的全大写金融缩写，默认保留英文
   - 指数与合约（举例 + 通用规则）：S&P 500 / Nasdaq 100 / CSI 300 / 恒生指数 / 标普 500 期货 / 10 年期美债收益率
     **规则**：指数名与合约月份保留原文写法
   - 加密技术：Layer2 / Rollup / ZK / EVM / RPC / Oracle / Multisig / Smart Contract
   - 通用技术：API / SDK / CLI / SaaS / CDN / SSO / OAuth / JWT / WebSocket / SSE / gRPC

3. 中国机构**优先用官方中文名**（首次出现可双标"中国证监会（CSRC）"，后续选一种保持一致）：
   - 中国人民银行（PBOC）/ 中国证监会（CSRC）/ 香港证监会（SFC）/ 国家统计局 / 上交所 / 深交所 / 北交所 / 港交所（HKEX）/ 国家外汇管理局 / 财政部 / 发改委 / 东方财富 / 华尔街见闻 / 中概股（不译"中国概念股"）

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - API 调用、合约地址（0x…）、区块高度、交易哈希不译不改写
   - URL 原样
   - 数字+单位：$3.2B / 12.5% / 45,000 美元 / 3.5x / 21 万枚 BTC / 5 年期 / 99.9%
   - 金额、市值、涨跌幅、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10B-$100B 改写成“数百亿至数千亿美元”等中文数量词
